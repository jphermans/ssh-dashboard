File transfer

Open an SSH session, then choose Files… in its header. Transfers use your SSH config, key and ssh-agent.

How do I upload files or folders?

In Files…, keep Upload to instance selected. Either drag files or folders onto the window, or use Choose files… / Choose folder…. Enter the remote destination (for example ~/incoming) and press Start transfer.

Use Browse… beside the remote destination to open the live remote file list and select the destination folder. Folders are copied recursively. After a successful upload the source list is cleared so the same files are not copied a second time by accident. A failed or cancelled transfer keeps the list for retry.

Where do downloads go?

Choose Download from instance, use Browse… to open the remote file list and select a file or folder, then press Start transfer. The destination defaults to your Downloads folder. Use Choose folder… if you want a different location.

Why does the transfer stop or ask for authentication?

If the host requests a password, a hidden password prompt opens. It is used only for that operation and is never saved. A key or an unlocked ssh-agent avoids the prompt. Check that the host has the right IdentityFile, or load your key with ssh-add.

Progress is shown live when rsync is available; otherwise the app falls back to scp with an indeterminate bar. Cancel stops the active process.

Host blocks

How do I add a Host block?

Open Configuration and choose Add block in the footer, or use Tools → Add Host Block… or Cmd/Ctrl+N. Enter the patterns, HostName, User, Port and IdentityFile.

The block is appended to the main ~/.ssh/config with a timestamped backup first. Existing blocks, comments and Include files are untouched. A global Host * block is refused.

How do I edit an existing block?

Double-click a Configuration row, or select it and use Edit block. Patterns and common options are editable; comments and options the app does not manage are preserved.

Safe changes and recovery

How do I delete a known_hosts entry?

Select the row and press Delete, or tick its checkbox and use Remove selected. Only the matching line is removed. Entries from Included config files are read-only here.

Where are the backups?

Every write creates a timestamped copy under ~/.ssh/.sshdashboard/backups. Open Backups… from the Tools menu to list and restore one. Undo restores every file touched by the last action.

Retention is 30 days or 200 files, whichever is reached first. Backups stay local; nothing is uploaded.

macOS notes

The app is blocked on first launch

The macOS build is ad-hoc signed and not notarized. Use System Settings → Privacy & Security → Open Anyway once. The current build is Apple silicon only; Intel Macs are no longer supported.

Can I install it from the Mac App Store?

No. The App Store requires the App Sandbox, which cannot reach ~/.ssh or run the system ssh, scp and puttygen the way this app does. The direct download is the supported distribution.

Still stuck? Open an issue with the app version, macOS version and the exact message. Include the relevant part of ~/.ssh/config only after removing private hostnames and keys.
